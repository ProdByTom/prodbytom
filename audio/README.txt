Put your MP3 files in this folder with these names (or edit the data-src values in index.html):

  showreel.mp3   - the hero showreel player
  track-01.mp3   - Fade
  track-02.mp3   - Spanish Drill (with Prod.Bingoo)
  track-03.mp3   - Bounce
  track-04.mp3   - RnB Type Beat
  track-05.mp3   - Basic (with Lucz)
  track-06.mp3   - GreenLight (with Bookz)
  track-07.mp3   - NOW

Durations fill in automatically. The waveform shapes come from each file's measured loudness (data-peaks in
index.html), so if you replace a file, ask for its waveform to be re-measured.
